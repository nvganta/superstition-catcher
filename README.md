# Superstition Catcher

A browsable catalog of Indian superstitions, organized by region and category,
with search, a "superstition of the day," and an admin page for submissions.

## State

Dormant since 2026-03-12. Feature-complete enough that the last work was
mobile polish. Data lives in a static in-repo store, no database.

## Stack

Next.js App Router, TypeScript, Tailwind.

## Running

```bash
npm install
npm run dev
```
